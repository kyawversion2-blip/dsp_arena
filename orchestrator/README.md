# DSP Arena Minimal Orchestrator

This is a provider-neutral, local-first control-plane scaffold. The current
machine is only an execution host; no permanent Mac dependency is encoded.

## Topology

- **Control plane:** task graph, dispatcher, collector, validators, and Git
  baseline capture. It may run on any supported host.
- **OCI worker:** persistent worker, read-only by default. No OCI connection or
  mutation is implemented here.
- **Kaggle worker:** disposable burst experiment worker. No Kaggle connection is
  implemented here.
- **Agent runtimes:** Codex, Qoder, Hermes, and OpenCode are adapter identities,
  not orchestration dependencies. Only the local subprocess adapter exists.

Roles are represented by `TaskEnvelope.role`: `architecture`, `coding`,
`dsp_scientific`, `data_ml`, `vision_chart`, `independent_audit`, and
`integration_validation`.

## Execution flow

1. Load immutable task envelopes and validate their explicit DAG dependencies.
2. Select tasks whose dependencies have succeeded.
3. Create a task-specific workspace under `.orchestrator/workspaces/`.
4. Capture the Git `HEAD` and worktree status before execution.
5. Run an allowlisted argv command with `shell=False`, `stdin=DEVNULL`, a
   bounded timeout, and a filtered environment.
6. Capture stdout/stderr as content-addressed artifacts.
7. Validate result identity, evidence labels, artifact hashes, and status.
8. Retry only bounded transient/provider/timeout failures.

Dry-run mode validates the task and records an observed skip without launching
a subprocess.

## Security boundaries

Enforced locally:

- no shell expansion;
- explicit executable allowlist when supplied;
- task workspace as subprocess working directory;
- timeout;
- stdin disabled;
- environment copied only from an explicit allowlist;
- stdout/stderr captured as artifacts;
- no Git mutation commands in the dispatcher.

Policy-only until a stronger sandbox is added:

- `network: disabled` is recorded and exported as a policy variable, but the
  local subprocess adapter cannot enforce OS-level network isolation;
- arbitrary filesystem access performed by a permitted program is not sandboxed;
- OCI read-only and Kaggle-disposable policies are contracts only because no
  remote adapters exist;
- secret redaction is limited by environment allowlisting; command output is
  captured verbatim and must not contain secrets.

## Git and artifacts

Git remains authoritative for source and configuration. The dispatcher never
commits, resets, stashes, checks out, or cleans. Artifacts live under
`.orchestrator/` and include SHA-256 references. Existing worktree changes are
captured in a baseline artifact and are not overwritten.

## Scientific boundary

The orchestrator does not measure audio or alter DSP behavior. It preserves the
canonical boundary:

`REAL AUDIO -> EVENT DETECTION -> DSP -> CANONICAL FEATURE VECTOR -> FEATURE SPACE -> CHART COORDINATES`

AI output is not measurement, ground truth, or chart-coordinate authority.
Missing WAV fixtures are never generated by this scaffold.
